# Simple Linear Regression – Student Marks Prediction

## 1. Project Overview

This project implements Simple Linear Regression, a Supervised Machine Learning algorithm, to predict student examination scores based on the number of hours they study.

## 2. Algorithm

- Machine Learning Category: Supervised Learning
- Algorithm: Simple Linear Regression
- Problem Type: Regression

## 3. Dataset

Dataset: Student Study Hours

Source: Kaggle – Student Study Hours Dataset

Features:
- Hours: Number of hours studied.
- Scores: Student examination scores.

## 4. Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## 5. Mathematical Formula

Linear Regression equation:

Y = mX + C

Where:
- Y = Predicted output
- X = Independent variable
- m = Slope
- C = Intercept

## 6. Implementation Steps

1. Import Python libraries.
2. Load the dataset.
3. Perform Exploratory Data Analysis (EDA).
4. Check missing and duplicate values.
5. Visualize the relationship between variables.
6. Separate independent and dependent variables.
7. Split data into training and testing sets.
8. Train the Linear Regression model.
9. Predict student scores.
10. Evaluate model performance.
11. Visualize the regression line.
12. Perform predictions for new students.

## 7. Model Evaluation

The model is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

Actual evaluation results are available in the Jupyter Notebook.
