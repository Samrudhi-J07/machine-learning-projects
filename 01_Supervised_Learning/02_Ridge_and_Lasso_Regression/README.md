# Ridge and Lasso Regression

## Overview
This project demonstrates Ridge Regression and Lasso Regression, two regularization techniques used in Machine Learning to prevent overfitting.

## Algorithms Implemented
- Ridge Regression (L2 Regularization)
- Lasso Regression (L1 Regularization)

## Dataset
**50_Startups.csv**

The dataset contains information about 50 startups, including:
- R&D Spend
- Administration
- Marketing Spend
- State
- Profit

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook / Google Colab

## Project Workflow
1. Import required libraries.
2. Load the dataset.
3. Perform data exploration and preprocessing.
4. Split data into training and testing sets.
5. Apply feature scaling.
6. Implement Ridge Regression.
7. Implement Lasso Regression.
8. Evaluate model performance using MAE, MSE, and R² Score.
